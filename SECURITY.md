# Security reporting

Report vulnerabilities through the repository's **Security → Report a vulnerability** private reporting form. Do not open a public issue containing exploit details, credentials, customer data or production logs.

The current 0.1 release line receives security fixes. Use immutable dependency/image versions and verify provenance. The supervisor coordinates cooperative processes; it is not a sandbox for hostile code. Clients must enforce authorization, process/container isolation and least-privilege device access.
