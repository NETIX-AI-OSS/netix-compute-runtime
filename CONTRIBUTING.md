# Contributing

Open an issue describing a generic runtime problem, then submit a focused PR with tests. Run the commands in README.md before submitting. Keep model implementations, weights, training data, prompts, rewards, tenant identifiers and deployment credentials in client repositories.

Contributions must be your work or properly attributed material you have permission to contribute under Apache-2.0. Preserve third-party notices. Sign commits with `git commit -s` to certify the Developer Certificate of Origin at https://developercertificate.org/.

Do not submit logs containing credentials or customer data. Report security problems privately as described in SECURITY.md.
